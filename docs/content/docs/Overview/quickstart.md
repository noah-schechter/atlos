This page walks you through setting up your first Atlos investigation. It should take about ten minutes. By the end, you'll have a project, an incident with archived source material, and a collaborator.

If you're not sure whether Atlos is the right tool for your work, read [What is Atlos?](/overview/what-is-atlos/) first.

## 1. Create an account

Sign up at [platform.atlos.org](https://platform.atlos.org). We recommend enabling two-factor authentication immediately — see [Account](/profiles/account/) for instructions.

If your work is politically sensitive, consider signing up under a pseudonym. See the [security and risk model](/safety-and-security/risk-model/) for guidance.

## 2. Create a project

Projects are the top-level container for an investigation. Each project has its own members, attributes, and incidents.

1. From the home page, click **Create project**.
2. Give the project a name and short description.
3. Choose whether to enable Internet Archive integration. (You can change this later.)

For more on projects and how they're structured, see [Key concepts](/overview/key-concepts/) and [Projects](/investigations/projects/).

## 3. Add your first incident

An incident is a single event you're documenting — for example, "Strike on residential building, Kharkiv, 2024-03-12".

1. Inside your project, click **New incident**.
2. Write a short description (at least 8 characters).
3. Mark the sensitivity level. If the source material may contain graphic content, mark it accordingly so your collaborators get a warning before viewing.
4. Add at least one URL as source material. Atlos will attempt to archive the page automatically.

For more on incidents, see [About incidents](/incidents/incidents/).

## 4. Invite a collaborator

1. Open your project's **Access** page.
2. Click **Create invite link**.
3. Choose a permission level (Viewer, Editor, Manager, or Owner) and copy the link.
4. Send the link to your collaborator.

For permission level details, see [Collaborate](/investigations/collaboration/).

## 5. (Optional) Connect the API

If you plan to integrate Atlos with other tools — Bellingcat's auto-archiver, a custom scraper, a mapping tool — generate an API token from the **Access** page and read the [API reference](/technical/api/).
